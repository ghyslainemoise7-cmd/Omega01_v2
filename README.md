# ☆ ØMEGĀ♧01 — nouvo baz pwojè

- Vercel Framework: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Environment variables: `VITE_SUPABASE_URL` ak `VITE_SUPABASE_ANON_KEY`
- Itilize sèlman Supabase publishable/anon key nan frontend. Pa janm mete `service_role` oswa sekrè.

San Supabase variables yo, sit la rete nan mòd demonstrasyon. Enskripsyon ak upload bezwen Supabase ak RLS/Storage policies ki byen mete. Upload yo antre ak `pending`; yo pa parèt jiskaske yo apwouve. Like yo se demo lokal, kòmantè ak pataj poko sove nan bazdone. Revize sekirite, moderasyon, RLS ak règleman konfidansyalite anvan piblikasyon piblik.
